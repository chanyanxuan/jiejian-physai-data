# Benchmark 报告 · 失效案例基准回归

> 判案层（缺陷检查规则集）的回归基准：任何规则变更，必须漏报、误报双零才能上线。

| 指标 | 结果 |
| --- | --- |

## 覆盖的缺陷类型（部分）

| 缺陷类型 | 机理 | 代表案例 |
| --- | --- | --- |
| rigid_translation | 约束不足引发刚体平动模态 → 零主元 | 悬臂梁漏约束 U2 |
| rigid_rotation | 约束未钉住绕轴转动 | 铅芯橡胶支座 |
| temperature_unconstrained | 耦合单元 DOF 11 无温度边界 → 温度场奇异 | 无人机热-力耦合 |
| tie_overconstraint | 节点同时属多个 Tie 从面 → OVERCONSTRAINT | 铅芯橡胶支座 |
| undefined_surface | Tie 引用表面未定义（装配与部件不一致） | 铅芯橡胶支座 |
| isolated_nodes | 孤节点无连接 → 刚度奇异 | 灵巧手等 |
| unit_inconsistency | 密度/单位制不自洽 | 多案例 |

## 验证方法

1. 每个案例：提交报错模型 → 判案层检出缺陷 → 白名单干预修复 → **重新提交求解器验证**；
2. 修复后求解完成（COMPLETED）才计入"命中"；
3. 规则变更触发全量回归：17 案例任一漏报/误报即回滚。

## 说明

- 案例模型基于公开可获取的产品三维模型构建，缺陷按 Abaqus 常见失效模式注入；
- 本报告仅公开统计结果；判案规则实现见商业授权部分。
