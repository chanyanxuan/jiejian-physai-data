# 样例案例：四旋翼无人机 · 热-力耦合失效（完整交付文件包）

## 案例概述

- **模型**：四旋翼无人机结构，8 节点耦合温度-位移实体单元 C3D8T 离散，材料铝合金 Al6061（E=68900 MPa，ν=0.33）
- **工况**：5 个分析步（Hover → Climb → Gust → Thermal → Landing），前 3 步静力，第 4 步热-力耦合
- **载荷/约束**：电机节点集竖向集中力 19.6 N；机身中心与起落架底部固定

## 错误 → 诊断 → 修复 → 验证 全流程

| 阶段 | 内容 |
| --- | --- |
| 错误 | Thermal 步第 1 增量步终止，报错 `TOO MANY ATTEMPTS MADE FOR THIS INCREMENT` |
| 诊断 | 全模型 C3D8T 单元（激活 DOF 11 温度自由度），但 5 个分析步均无温度边界条件 → 温度场存在刚体平移零能模态，节点 10 处 DOF 11 零主元（~10¹² 量级）；数据文件同时记录绝对零度未定义 |
| 修复 | 耦合分析步内为 Motors 节点集补充温度边界（DOF 11 = 100.0），后续步重置机械边界 |
| 验证 | 修复后重新提交求解，**5 个分析步全部完成（COMPLETED）** |
